## Known limitations and deferred risks

- Windows CI builds but does not execute tests for `sync-engine` (`rusqlite`'s bundled SQLite and `libsql`'s bundled SQLite define duplicate C symbols under MSVC's linker — documented in `.github/workflows/rust-tests.yml`).
- Android CI is cross-compile build/check only, no test execution (no Android test host); `diarize`/`ffi` excluded (no prebuilt ONNX Runtime for that target).
- The Google Calendar connector's dependency tree carries 3 pre-existing npm advisories (`hono` moderate, `nanoid` high) — upstream, unrelated to this cutover, not remediated here.
- GitHub Dependabot separately reports 25 open alerts repo-wide (9 high, 12 moderate, 4 low) as of this push — not triaged as part of this release.
- Kestrel is a personal-beta project with no App Store distribution and no external user base; this release cutover establishes the provenance chain going forward, not a security guarantee about any code shipped before it.
