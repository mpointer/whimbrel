System requirements

  • Windows 11, 64-bit (x64)Windows on ARM is not supported yet.
  • Microsoft Edge WebView2Already included with Windows 11.
  • Disk spaceRoom for the app, the on-device speech model, and your growing history.
  • Optional: OllamaTo run language models fully on your PC.

Install in two minutes

  1. Run the downloaded Whimbrel_x.y.z_x64-setup.exe.
  2. If SmartScreen appears, choose More info → Run anyway (see below why).
  3. The installer finishes without needing administrator rights.
  4. Whimbrel starts in the system tray. Open it to finish setup.
  5. Connect your calendar so recordings start with your meetings.
