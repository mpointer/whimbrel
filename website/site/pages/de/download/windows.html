Whimbrel für Windows

Dasselbe private Gedächtnis und dieselbe Meeting-Aufnahme ohne Bot wie auf dem Mac, jetzt auf Ihrem Windows-PC, mit einer gemeinsamen Zeitleiste für Ihre anderen Geräte.

{{{site.renameNote}}}
Für Windows herunterladen

Zum ersten Mal hier? Vor dem Start des Downloads werden Sie gebeten, sich zu registrieren.

Ein PC mit Arm-Prozessor (etwa Snapdragon)? Laden Sie Windows on Arm herunter. Diese Version läuft nativ, die Transkription ist daher schneller als mit der normalen Version unter Emulation.

{{> app-mock}}

Systemvoraussetzungen

  • Windows 11, 64 Bit (x64 oder Arm)Nutzen Sie auf einem Arm-PC den Download für Windows on Arm. Er unterscheidet die übrigen Sprecher in einem Anruf noch nicht.
  • Microsoft Edge WebView2Ist in Windows 11 bereits enthalten.
  • SpeicherplatzPlatz für die App, das Sprachmodell auf dem Gerät und Ihren wachsenden Verlauf.
  • Optional: OllamaUm Sprachmodelle vollständig auf Ihrem PC auszuführen.

Installation in zwei Minuten

  1. Starten Sie die heruntergeladene Datei Whimbrel_x.y.z_x64-setup.exe (_arm64-setup.exe unter Windows on Arm).
  2. Wenn SmartScreen erscheint, wählen Sie Weitere Informationen → Trotzdem ausführen (den Grund finden Sie weiter unten).
  3. Die Installation wird ohne Administratorrechte abgeschlossen.
  4. Whimbrel startet im Infobereich der Taskleiste. Öffnen Sie es, um die Einrichtung abzuschließen.
  5. Verbinden Sie Ihren Kalender, damit Aufnahmen mit Ihren Meetings starten.
