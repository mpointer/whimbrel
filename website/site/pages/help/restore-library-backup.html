Restoring a library backup

For Whimbrel on a Mac.

Before you start: your library is one file, core-memory.sqlite, in Whimbrel's data folder. Restoring means putting a backup copy of that file in its place. Move files aside instead of deleting them, and keep them until you are sure the backup opened.

Steps

  1. Open the data folder. In Whimbrel, open Settings, then Capture & Privacy, then Your data, and click Show in Finder. Keep that Finder window open.
  2. Quit Whimbrel and wait until it has closed. Never change these files while Whimbrel is open.
  3. Move the current library out of the folder. Move core-memory.sqlite and, if they are there, core-memory.sqlite-wal, core-memory.sqlite-shm and core-memory.sqlite-journal to another folder, for example on your Desktop. Do not delete them yet. Leave every other file in the data folder as it is.
  4. Put the backup in. Copy your backup of core-memory.sqlite into the data folder under that exact name. If your backup also holds a -wal or -shm file saved at the same time as it, copy those too, named core-memory.sqlite-wal and core-memory.sqlite-shm: they belong to that copy. Never leave the ones you moved out beside it: a -wal file from another copy can damage the backup.
  5. Open Whimbrel.

What Whimbrel does next

  • An encrypted backup made with this Mac's current key opens as usual.
  • An encrypted backup made with an earlier key shows the recovery screen. Unlock it with the recovery file and its passphrase, or with your 24 recovery words, for that earlier key.
  • A backup from before you turned on encryption is an unencrypted file. Whimbrel opens it. If this Mac's library was encrypted before, Whimbrel may encrypt the backup again at that launch, with a progress screen; otherwise the encryption card in Settings offers to encrypt it.

A recovery key unlocks a library file. It cannot bring back a library whose file is gone, so you need the backup file itself.

If it does not open

Keep the files you moved aside and the backup, and write to {{site.contactEmail}}. Do not delete anything until the library you want opens.
