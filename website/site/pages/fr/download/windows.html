Configuration requise

  • Windows 11, 64 bits (x64)Windows sur ARM n'est pas encore pris en charge.
  • Microsoft Edge WebView2Déjà inclus dans Windows 11.
  • Espace disqueDe la place pour l'application, le modèle de reconnaissance vocale sur l'appareil et votre historique grandissant.
  • Facultatif : OllamaPour exécuter des modèles de langage entièrement sur votre PC.

Installation en deux minutes

  1. Lancez le fichier téléchargé Whimbrel_x.y.z_x64-setup.exe.
  2. Si SmartScreen s'affiche, choisissez Informations complémentaires → Exécuter quand même (voir plus bas pourquoi).
  3. L'installation se termine sans droits d'administrateur.
  4. Whimbrel démarre dans la zone de notification. Ouvrez-le pour terminer la configuration.
  5. Connectez votre calendrier pour que les enregistrements démarrent avec vos réunions.
