Bêta de l’application pour téléphone

Essayez Whimbrel sur votre téléphone

L’application pour téléphone affiche les réunions que Whimbrel enregistre sur votre Mac ou votre PC Windows. Lisez les notes, les décisions et les actions à faire où que vous soyez.

  • Il vous faut Whimbrel sur un Mac ou un PC Windows. Le téléphone n’enregistre pas les réunions lui-même.
  • Pas encore d’ordinateur ? Vous pouvez quand même faire la demande. Nous la gardons.
  • Nous approuvons chaque personne une à une et vous écrivons quand votre place est prête.
  • iPhone : avec TestFlight d’Apple. Android : un téléchargement direct.
