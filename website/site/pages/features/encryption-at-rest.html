Mac and Windows

Encrypt Whimbrel's memory database on your computer.

The memory database can be encrypted on your computer. A copy of the database file (one in a backup, a synced folder, or another account on the same computer) can't be read without its key. Only the database is encrypted: audio and other files are not, so a backup of the whole folder still holds them. Copies made before you turned it on are not covered; see below.

What it does.

The key is kept in the Keychain or Credential Manager

Whimbrel keeps the key in the Keychain on the Mac and in Credential Manager on Windows. The key is not in the database file.

Opt-in for an existing install

New installs are encrypted from the first launch. An existing install stays as it is until you choose Settings → Capture & Privacy → "Encrypt the database". It encrypts at the next launch. On the Mac it first offers Export everything.

A recovery key you keep elsewhere

Encrypting asks you to create a recovery key: a recovery file with a passphrase, plus 24 words. Keep them somewhere other than this computer.

If the key is lost.

If the key is lost (a new computer, a reset Mac Keychain, or a new Windows profile), a recovery screen opens the database with either the recovery file and its passphrase, or the 24 words. Whimbrel never deletes or replaces a database it can't open. The 24 words are the key itself: your passphrase does not protect them, and anyone who has them can read the memory database, so keep them offline. If the key is lost and you have neither the words nor the recovery file and its passphrase, the database cannot be opened, by you or by Whimbrel.

What is not encrypted.

Only the memory database is encrypted. Recordings, slide images, exports, the Obsidian vault, captured screen text files, settings, logs and diagnostics stay ordinary files. Audio and other files are not encrypted. Each computer encrypts its own database, so turning it on here does not turn it on for your other computers. Phones are not covered: a phone keeps what syncs to it in its own database, which this does not encrypt. Sync itself is unchanged and stays end-to-end encrypted.

To cover recordings and the other files as well, turn on FileVault on a Mac or BitLocker on Windows, which encrypts the whole disk.

What it does not do.

It does not protect against someone using your unlocked computer, or other software running as you: Whimbrel can read the key, so they can too. Backups made before you turned it on still hold a readable copy, and after an existing install is encrypted Whimbrel keeps an unencrypted copy until it has started normally three times, then deletes it. A full-machine backup or move that includes your Mac's login keychain (Time Machine, Migration Assistant) carries the key, and on a work PC with a roaming Windows profile the key can travel with the profile.

If you use a hosted AI model, the text of that request goes to the provider you chose. With Whimbrel AI, it goes through Whimbrel's server to Anthropic; Whimbrel keeps a token count, not what you asked. Recordings, transcripts and history are stored on your computer, not on our servers.

Search speed and Delete everything.

"Faster search (uses more memory)" gives search up to 1 GB more memory on a computer with at least 16 GB. "Check encryption speed" times search on your own data and keeps the report on your computer.

Delete everything also removes the database keys. API keys and sign-ins are kept.
