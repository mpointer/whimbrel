# English variants (en-GB, en-CA, en-AU)

The source is US English. A variant catalog holds deltas only.

- Return only strings whose spelling or wording differs in the target variant. Leave out every string that reads the same; the app falls back to the US English source for it.
- Change spelling and wording only. Do not rewrite, shorten, or "improve" a string that is already correct in the variant.
- en-GB and en-AU: -ise/-isation (organise, recognise), colour, favourite, behaviour, centre, cancelled, licence (noun), programme (not for computer programs), catalogue.
- en-CA: Canadian spelling: colour, favourite, behaviour, centre, cancelled, licence (noun), but -ize (organize, recognize) and program.
- Dates and numbers are formatted by the OS locale; never rewrite a placeholder to change date order.
- Product names (Whimbrel, Ask, Away Mode, Today, Recap, Routines, skin) never change.
