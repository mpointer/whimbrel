# German (de; Germany)

- German as used in Germany. Address the user as Sie, never du.
- Keep it short: German runs long, and UI labels and Today headers have tight limits. Prefer compact words over long compounds where both are natural.
- Use sentence case for UI labels, with nouns capitalized as German requires.
- Keep every placeholder (%@, %lld, %1$@, {name}) exactly as written, in a natural position for German.
- Product and feature names stay in English: Whimbrel, Ask, Away Mode, Today, Recap, Routines, skin.
- Skin voice lines keep the skin's register: Almanac stays old-fashioned, Retro Terminal stays terse.
- Dates and numbers are formatted by the OS; do not write them out.
