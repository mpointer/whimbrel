# Canadian French (fr-CA)

- Canadian French, as used in Quebec software. Address the user as vous.
- Put a space before : ? ! and ; (a non-breaking space, U+00A0). Use guillemets « » with inner spaces for quotes.
- Prefer Quebec usage where it differs from France: courriel (not e-mail), clavarder only if the source says chat as a verb.
- Keep it as short and plain as the English; UI labels are short.
- Keep every placeholder (%@, %lld, %1$@, {name}) exactly as written, in a natural position for French.
- Product and feature names stay in English: Whimbrel, Ask, Away Mode, Today, Recap, Routines, skin.
- Skin voice lines keep the skin's register: Almanac stays old-fashioned, Retro Terminal stays terse.
- Dates and numbers are formatted by the OS; do not write them out.
